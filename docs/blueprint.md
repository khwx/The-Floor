# **App Name**: Tile Takeover

## Core Features:

- Single Player Mode: The user plays against the computer in a one-on-one strategic battle to control the floor tiles.
- Team Play Mode: Players can form teams and compete against other teams, coordinating their moves to dominate the floor. Teams will play against the AI to conquer new tiles
- Floor Division: AI-powered tool that distributes initial territories. Based on difficulty, the floor will have varying amounts of different themes
- Category Selection: Players will pick a question category before claiming a tile.
- Tile Conquest: When a player correctly answers the question in the chosen category, they gain control of that tile. Tiles must be adjacent to ones controlled by the user already.
- Themed Floors: Visually distinct tiles with a cohesive look (e.g., historical landmarks, science, animals, general trivia, etc.).
- Scoreboard: Track each player/team's progress and display their score relative to others

## Style Guidelines:

- Primary color: Vivid purple (#9400D3), inspired by the concept of intellectual competition, balancing sophistication and fun.
- Background color: Light purple (#F2E7FF), desaturated to create a sophisticated yet unintrusive backdrop that allows the game elements to stand out.
- Accent color: Electric blue (#7DF9FF), for interactive elements and highlights, chosen for high contrast against the purple hues, adding an element of vibrancy.
- Body and headline font: 'Inter', sans-serif, for a clean and modern user interface that ensures readability and clarity.
- Use a set of minimalist icons for in-game actions such as selecting categories, challenging tiles, and viewing scores, keeping the design coherent.
- Design a responsive grid-based layout for the floor and implement dynamic scaling, maintaining usability and readability across devices.
- Add smooth transitions between turns and gentle animations when claiming a tile, enriching user experience.
